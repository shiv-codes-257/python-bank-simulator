# Python Bank Account Simulator

## Description
A beginner-friendly banking simulator built with Python. It allows users to perform basic banking operations through an interactive menu in the terminal.

## Features
- Create an account with a user's name
- Deposit money into an account
- Withdraw money from an account
- Check the current account balance
- Validate deposit and withdrawal amounts
- Prevent withdrawals that exceed the available balance
- Interactive menu with an option to exit

## Technologies
- Python 3
- Variables and data types
- User input and type conversion
- Conditional statements (`if`, `elif`, `else`)
- Loops
- Basic arithmetic and input validation

## How to Run
1. Install Python 3.
2. Download `banksimulator.py` from this repository.
3. Open a terminal in the folder containing the file.
4. Run the following command:

   `python banksimulator.py`
